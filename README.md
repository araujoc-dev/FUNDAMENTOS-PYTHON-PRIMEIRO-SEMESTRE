# Exercícios de Python - 1º Semestre de ADS 🐍

Este repositório contém as soluções dos exercícios práticos de lógica de programação e algoritmos desenvolvidos durante o primeiro semestre do curso de Análise e Desenvolvimento de Sistemas (ADS). 

O foco principal é o aprendizado da linguagem Python e a construção de uma base sólida em lógica e estruturas de dados.

## 🗂️ Estrutura do Repositório

Os exercícios estão divididos em módulos progressivos de aprendizado:

*   **`01_entrada_e_saida/`**: Exercícios focados nas funções básicas de interação com o usuário (`input()` e `print()`) e conversão de tipos (casting).
*   **`02_operadores/`**: Práticas de expressões matemáticas utilizando operadores aritméticos (`+`, `-`, `*`, `/`, `%`, `//`).
*   **`03_operadores_logicos_e_relacionais/`**: Resolução de problemas utilizando operadores de comparação (`>`, `<`, `==`, `!=`) e operadores lógicos (`and`, `or`, `not`).
*   **`04_estrutura_de_decisao/`**: Implementação de controle de fluxo condicional utilizando `if`, `elif`, `else` e `while` para criação de lógicas de validação e tomada de decisão.

## 🛠️ Tecnologias Utilizadas

*   **Linguagem:** Python 3.x
*   **Ambiente de Desenvolvimento:** Visual Studio Code (VS Code)
